# محلل البيانات المرورية وحركة المشاة الذكي | Bridge Traffic & Pedestrian AI Analyst

تطبيق **Streamlit + Gemini AI** ثنائي اللغة (**العربية أولًا مع دعم كامل للاتجاه من اليمين إلى اليسار RTL + الإنجليزية**) لتحليل بيانات الحصر المروري وحركة عبور المشاة (مشروع دراسة حركة المرور وكوبري المشاة — **11 إلى 17 أكتوبر 2026**).

يجمع التطبيق بين **لوحة المؤشرات التنفيذية المعتمدة (Power BI Reference Parity)** وميزة البطل التفاعلية **«اسأل بياناتك / Ask Your Data»** التي تتيح طرح أي سؤال استكشافي جديد باللغة العربية أو الإنجليزية والحصول على إجابة تحليلية موثقة من 5 أجزاء محسوبة فعليًا عبر Python ومقترنة برسم بياني تفاعلي وجدول أدلة قابل للتنزيل وتوثيق كامل لطريقة الحساب (`طريقة الحساب / How this was calculated`).

## 1. المتطلبات الأساسية لبيئة المطورين (Developer Prerequisites)

- نظام التشغيل: **Windows 10 / 11** (أو أي نظام يدعم Python).
- إصدار بايثون: **Python 3.10+** (تم التحقق والاختبار على Python 3.12).
- مفتاح **Google Gemini API** (اختياري للتشغيل الكامل؛ يعمل التطبيق تلقائيًا بوضع التحليل الحتمي الموثق `Verified Deterministic Mode` في حال عدم ضبط المفتاح أو انقطاع الاتصال).

## 2. خطوات التثبيت والتشغيل على Windows PowerShell

افتح نافذة **PowerShell** وانتقل إلى مجلد المشروع ثم نفّذ الأوامر التالية بالترتيب:

```powershell
# 1) الانتقال إلى مجلد المشروع
cd "c:\Users\NOUR SOFT\Downloads\Bridge_Traffic_AI_Streamlit_OneShot_Handoff\Bridge_Traffic_AI_Streamlit_OneShot"

# 2) إنشاء بيئة افتراضية جديدة (Virtual Environment)
python -m venv .venv

# 3) تفعيل البيئة الافتراضية على Windows PowerShell
# (في حال ظهور تحذير ExecutionPolicy يمكنك تنفيذ: Set-ExecutionPolicy -Scope Process -ExecutionPolicy Bypass)
.\.venv\Scripts\Activate.ps1

# 4) تثبيت المكتبات المطلوبة
pip install --upgrade pip
pip install -r requirements.txt

# 5) ضبط مفتاح Gemini API في متغير البيئة للجلسة الحالية (اختياري وموصى به)
# استبدل YOUR_GEMINI_API_KEY_HERE بمفتاحك الفعلي دون حفظه داخل الكود
$env:GEMINI_API_KEY = "YOUR_GEMINI_API_KEY_HERE"

# 6) تشغيل تطبيق Streamlit
streamlit run app.py
```

### التشغيل السريع بنقرة واحدة (Windows Batch)

## 5. القواعد التحليلية الصارمة المطبقة في النظام

1. **وحدة التحليل المعتمدة (`Direction-Hour Grain`)**:
   - يتكون جدول الرصد المدمج من `96` سجلًا تغطي `81` فترة اتجاه-ساعة فعلية (`43` ساعة في `من سندوب إلى الصينية` + `38` ساعة في `من الصينية إلى سندوب`).
   - توجد `15` فترة اتجاه-ساعة رُصدت بواسطة راصدين اثنين (`30` سجلًا خامًا)؛ يتم جمع أعدادها في مستوى الساعة الواحدة قبل حساب المتوسطات أو المئينات أو ساعات الذروة، ولا تُعامل أبدًا كصفوف مكررة يجب حذفها.
2. **الفصل التام بين المركبات والمشاة**:
   - تُقاس المركبات بوحدة **مركبة (`127,769` مركبة)** ويُقاس المشاة بوحدة **حركة عبور مشاة (`24,342` حركة عبور)**؛ يمنع النظام منعًا باتًا جمع الوحدتين في رقم إجمالي واحد.
3. **المقارنة العادلة بين الاتجاهين**:
   - يعرض النظام دائمًا إجمالي العينة الكاملة إلى جانب **متوسط الساعة الفعلي** (`1,726.70` مقابل `1,408.45` مركبة/ساعة) و**المقارنة المتناظرة في الساعات المشتركة الـ 38** (`65,279` مقابل `53,521` مركبة؛ بفارق `+11,758` مركبة أي `+21.97%`).
4. **الأمان وحماية الخصوصية والمفاتيح**:
   - لا يتم تخزين أي مفتاح API داخل الكود أو الملفات، كما يتم تعمية أسماء الراصدين تلقائيًا إلى معرفات تحليلية (`راصد #01` إلى `راصد #15`).
